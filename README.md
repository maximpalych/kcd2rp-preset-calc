# KCD2 RP — конструктор сетов

Одностраничный калькулятор рецептов для KCD Roleplay. Работает без сервера: база рецептов встроена в `index.html`.

## Возможности

- профессии бронника, портного, кузнеца и лучника;
- русский и английский интерфейс;
- расчёт промежуточных компонентов и общих партий;
- учёт купленных ресурсов, цен и платы за крафт;
- импорт и экспорт комплектов в JSON.

## Сборка и проверка

```bash
npm run build
npm test
```

`index.html` и `recipes.json` создаются из шаблона, исходной базы и словаря переводов.

## Публикация

Для Netlify выберите этот репозиторий, оставьте Build command пустым и укажите корень репозитория как Publish directory. Готовый сайт находится в `index.html`.
